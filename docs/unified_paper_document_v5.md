# 第一部分:复查——我们错在哪里

## 1. 四类错误

**(一)对照组是空的,或者和对手说的不是同一个东西。**

- v2–v4 的"谱分量"是 UᵀHV 的对角线,只管奇异值变不变。它只占更新能量的约 0.05%,所以"去谱"(frame_matched)和修复后的"保谱"(exact_iso)每一步和正常训练的余弦都是 0.9997。"保谱 = 去谱 = 正常训练"是必然的,不是发现。
- 对手说的是另一件事:The Path Not Taken(2511.08567)说 RL 的更新避开"主权重"和前几个奇异方向组成的主子空间;Jin 等(2509.12235)说遗忘来自两端奇异向量的**转动**,而奇异值本身几乎不变。**我们从没测过主子空间的转动,也从没对它做过干预。**
- "只沿主方向"和"只沿随机方向"两组:投影后和原更新的余弦约 0.021,等于随机水平;RLVR 下这两组几乎不训练(任务 KL 0.005,正常训练 0.60)。两个"几乎没动"的组比不出区别。

**(二)管线让"崩溃"和"遗忘"看起来存在,其实是测量假象。**

- RLVR 的奖励函数找不到 `####` 就取最后一个数字,而且不管回答有没有写完。lr×1 的 run 从第 31 步起每条回答都写满 384 token,奖励仍有 0.45–0.72:模型学会了不停地写数字刷分。v2–v4 叫它"崩溃"。
- 基座模型在 384 token 下有 72% 的回答写不完,所以 RLVR 的 GSM8K 提升有相当一部分是"学会写短"。
- MMLU 用第一个 token 在 A/B/C/D 上的打分,测的主要是答题格式:lr×1 的模型只有 2.5% 的题第一个词是字母,但生成的推理是对的。"全量 MMLU"用的是同一方法。
- 训练和评测的前向都是 bf16,KL 却用 fp32 算。按位移估算,RLVR 在 lr\* 下 bf16 模型里真正变了的权重只有约 6%(未验证,ckpt 已删)。
- SFT 在任何学习率下都让 GSM8K 下降(0.546 → 0.39–0.42),所以"SFT 的健康学习率"其实是"损伤最小的那一档"。健康检查从来不看任务分数。

**(三)计算错误。**

- v2 用来推翻 v1 的"只有 17–27% 的行能测出信号":把没有数据的 NaN 行算成了"没信号"(`analysis_v2/plot_v2.py:77`)。实际是 SFT 0.68、OPD 0.82、RLVR 0.52。
- v2 的"可复现信号的谱占比在随机基线":按独立两半重算,SFT/OPD 是随机基线的 4–5 倍(sft_adamw 95% 区间 [2.2, 5.9]),只是绝对值很小(约 0.1%)。RLVR 测不出。
- E-v4-4 的学习率倍率按矩阵个数归一,没按参数量,结果倍率组的实际步长大了 1.1–1.5 倍,"判负"不成立。
- "RLVR 的步子互相抵消":按每单位 ‖H‖² 比较,忽略了 SFT 的步长是 RLVR 的 5 倍;按绝对值外推,没有抵消。

**(四)推理和统计。**

- 用"差小于门槛且 |t| < 2"判"不可分":这不是等价检验,真实差正好等于门槛时也有一半机会判成"不可分"。2 个种子能检出的最小差是 0.046–0.069,比门槛 0.03 还大。
- 两个结论互相保护:"遗忘由累计功能步长决定"遇到反例(SFT r 维组任务外 KL 是正常训练的两倍,MMLU 却不掉)时,用"任务外 KL 不是遗忘的代理"把反例解释掉。这样结论永远推不翻。
- 总结时把证据升级:"全在 dense ±0.01 内"里 SFT 的三个组根本没测全量 MMLU,下界 0.448 来自已作废的 run;exact_iso 修复版在 RLVR 上差 −0.031、经验 t = −2.5,按自己的规则不通过,登记时却引用了 t_binom = −1.7。
- v1 的 H1 三个范式差 5%、都贴着随机基线,被标成"方向成立"。

## 3. 为什么 v5 选 v4 的问题,而不是回到 v1/v2

- v1/v2 的问题是"梯度的谱几何":可复现信号在谱方向的绝对占比约 0.1%。即使富集是真的,它能解释的训练效果也很小,做成方法的赔率低。
- v4 的问题是"遗忘的原因是方向还是步长":文献里有明确的对手(方向说:2511.08567、2509.12235、MiLoRA、RPSFT、LIFT;步长 / 分布说:RL's Razor 2509.04259、Retaining by Doing 2510.18874),而且**没有人做过按功能步长对齐的因果检验**(v4 文献调研的结论)。两种结果都有价值:方向在对齐步长后仍然起作用,是正结果;不起作用,是对一族方法前提的否定,而且有干净的因果证据。
- 我们已有的工具(逐步干预引擎、单步 KL 探针、逐矩阵归因)正好是做这件事需要的;缺的是正确的干预对象、正确的管线和正确的统计。
- v1 的"可复现信号谱富集"作为副线保留:在第 1 阶段顺带用大批量捕获重测(零额外训练),作为附录结果或以后的方向。

# 第二部分:v5 要回答的问题

**主问题:后训练的遗忘,是由更新的方向(是否转动、是否触碰预训练权重的主子空间)决定,还是由每一步让模型输出变了多少(功能步长)决定?**

拆成三个可检验的子问题:

- **Q1(现象)**:在修好的管线上,RL 在同样的任务收益下是否比 SFT 遗忘少?RL 的更新是否真的更少转动主子空间(对手的描述性现象能否复现)?这些差别是否在"功能步长相同"的 SFT 上就消失?
- **Q2(因果)**:把 SFT 的更新强行改成"不转动主子空间"或"完全避开主子空间",在**每一步功能步长相同**的条件下,遗忘是否减少?反过来,把 RL 的更新强行放进主子空间,遗忘是否增加?
- **Q3(数据还是目标)**:SFT 用模型自己的正确样本(on-policy 数据)与用教师样本,在功能步长对齐后遗忘差多少?这把"RL 目标"与"on-policy 数据"分开。Q3 优先级最低,Q1/Q2 结论清楚后再定。

**论文的主张会是下面二选一**(预先写明,数据出来前不改):

- A:方向起作用。对齐功能步长后,避开主子空间的 SFT 遗忘显著更少,且随机子空间的对照组没有这个效果。→ 第一个因果证据,并给出"按方向控制遗忘"的依据。
- B:方向不起作用。对齐功能步长后,各方向组的遗忘在预设的等价区间内相同,而学习率一档之差造成的遗忘差远大于该区间。→ 方向说的描述性证据来自步长混淆;控制遗忘应控制功能步长。

加上一节**测量陷阱**(附证据):范数对齐掩盖学习率缩小、宽松验证器加截断造成的刷分、字母打分 MMLU 的格式假象、bf16 前向看不见小更新、GPU 单精度 SVD 噪声、空干预。每一条都用我们自己的数据展示它能造出什么样的错误结论。这一节无论 A 还是 B 都成立。

## 1. 第 1 阶段:现象与对手现象的复现(Q1,约 5 天,0.8B)

- **学习率扫描**:RL 与 SFT(教师数据)各 4 档学习率 × 3 个种子 = 24 run;每 50 步存 ckpt 并评测。画"任务收益 vs 保持分数"的前沿。
- **对手的描述性统计**:对每个 ckpt 算主子空间转动角(前 k 个奇异向量,k 取秩的 1%、5%、10%)、归一化谱漂移、更新在主权重上的重叠比例,口径按 2511.08567 与 2509.12235 的定义实现。
- **关键对照**:把 SFT 的学习率调到"每步任务 KL 与 RL 相同"的档位(用 8 步探针定档),看 RL 与 SFT 在转动角和遗忘上的差别还剩多少。
- **顺带(零额外训练)**:在基座和 3 个 ckpt 上做 B = 64 的梯度捕获,按独立两半重测 v1 的谱富集(副线)。

**必须看到**:在同样的任务收益下 RL 的保持分数高于 SFT(差 ≥ 2 个点,3 种子,置信区间不含 0);RL 的主子空间转动小于 SFT。
**停止 / 转向**:在同样的任务收益下 RL 与 SFT 遗忘相同 → Q2 没有可以解释的差别;或者"SFT 调到同功能步长后,转动与遗忘都和 RL 一样" → 这本身就是 B 型结论的强证据,Q2 只做最小规模确认。

## 2. 第 2 阶段:因果检验(Q2,约 7 天,0.8B)

**干预(每一步对 SFT 的实际更新 H 做,基用当前 W 的 SVD,每步刷新,用高精度 SVD 驱动)**

记 Uₖ、Vₖ 为当前 W 的前 k 个左右奇异向量,P 为到它们张成的子空间的投影,P⊥ 为到补空间的投影。

| 组 | 做法 | 检验什么 |
|---|---|---|
| dense | 不改 | 参照 |
| 不转动主子空间 | 去掉 P·H·V⊥ 和 U⊥·H·P 两块(一阶下前 k 个奇异子空间不转动,奇异值可以变) | Jin 等的"转动致遗忘" |
| 避开主子空间 | 只保留 P⊥·H·P⊥ 这一块 | 2511.08567 / MiLoRA 的"避开主方向" |
| 随机子空间对照 | 同样两种操作,但换成同维数的随机正交子空间 | 区分"主子空间特殊"与"去掉一部分更新"本身 |
| (RL 反向)只在主子空间内 | 对 RL 的 H 只保留触碰主子空间的部分 | 反方向预测:RL 遗忘应增加 |

**步长对齐(三种口径,都报告)**

1. **单步任务 KL 对齐(主口径)**:每 10 步在一个固定探针批次上测 dense 更新与干预后更新的单步 KL,把干预后的更新乘以 s = √(KL_dense / KL_arm)(A5 已确认单步 KL 在此范围内是精确二次)。
2. **任务收益对齐**:每组扫 3 档学习率,在前沿上比较同样任务收益下的保持分数。
3. **范数对齐**(只作陷阱展示):重现 v2 的做法,展示它造成的步长缩小。

**非空检查(正式跑之前做,不过就不跑)**:每个干预组在 smoke 中必须满足:单步更新与 dense 的余弦 ≤ 0.95,或被去掉的能量 ≥ 10%;单步 KL 对齐后,干预组的单步任务 KL 与 dense 相差 < 10%。k 从 {1%, 5%, 10%, 20%} 里选第一个满足条件的档,并同时报告相邻一档。

**规模**:SFT 5 组 × 4 种子 × 主口径 = 20 run;前沿口径中 dense 与两种主干预组 × 3 档学习率 × 2 种子 = 18 run;RL 反向 2 组 × 4 种子 = 8 run。合计约 46 run。

**预先锁定的裁决**
- 主终点:300 步终点的保持分数(四项平均);次终点:任务分数、任务外 KL、主子空间转动角。
- 最小有意义差:保持分数 1.5 个点(第 1 阶段结束后按实测的学习率效应复核,只能调严不能调松)。
- "方向起作用":避开或不转动主子空间组比 dense 高 ≥ 1.5 个点(单侧检验 p < 0.05,4 种子配对),**且**比同操作的随机子空间对照高 ≥ 1.5 个点。
- "方向不起作用":所有方向组与 dense 的差在 ±1.5 个点内(TOST,p < 0.05),且第 1 阶段中学习率一档之差造成的差 ≥ 3 个点。
- 两者都不满足:写"无法裁决",加种子,不外推。

# 第四部分:防错规则(针对这次复查发现的 AI 失误)

1. **非空检查**:任何干预组正式跑之前,必须先证明它和 dense 真的不同(余弦、去掉的能量、单步 KL)。过不了就不跑,也不写进结论。
2. **对象对齐**:反驳谁,就按谁的定义实现测量,先复现对方的描述性现象,再做干预。
3. **预先锁定**:每个比较在看数据之前写清楚对齐口径、主终点、最小有意义差、种子数和检验力,写进登记处,之后只能调严。
4. **等价只用等价检验**:"不可分"必须过 TOST;检验力不够写"无法裁决",不写"成立"。
5. **独立复算**:每个进入结论的数字,由另一个独立脚本(另开一个子代理,只给原始文件)从原始 json/csv 复算一次,登记处标"已复算"。没复算的数字不进总结。
6. **健康曲线一起看**:奖励必须和截断率、回答长度、格式率、字母概率质量一起报告,任何一项异常先查管线,再谈训练现象。
7. **不升级证据**:总结里的每句话要能指回登记处的具体数字;"全部 / 都"类说法要列出覆盖了哪些 run。
8. **遇到反例先当真**:数据和主张冲突时,先检查主张,而不是引入新概念把反例解释掉。
9. **阶段收尾审查**:每个阶段结束前,用独立子代理对代码、管线、统计做一次对抗式审查(同本次),审查意见写进企划书再进下一阶段。

# 第五部分:可行性与赔率(老实估计)

- **第 0–1 阶段(约 8 天)一定有产出**:修好的管线、一套测量陷阱的证据、对手描述性现象能否复现、RL/SFT 遗忘差是否存在。这部分决定值不值得继续。
- **第 2 阶段**:只要第 1 阶段看到了遗忘差,A 或 B 两种结论都能写成文。风险在于"无法裁决"(效应小于种子噪声);用 4 种子配对和四项平均的保持分数降低这个风险。
- **第 3 阶段**:两个新设定里任何一个与 0.8B 方向相反,结论就只能写成有条件的;这是本工作最大的不确定性。
- **整体估计**:到可以投稿的完整度(三个设定、因果检验结论清楚、测量陷阱一节),把握大约四到五成。比 v4 暂停时的估计高,原因是这次的问题有明确对手、两种结果都有价值、第一周就能知道要不要继续。
