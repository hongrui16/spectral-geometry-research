# 第一部分:现阶段总结

## 1. 我们分析了什么

- **对象**:Qwen3.5-0.8B 在 GSM8K 上的后训练,SFT 与 RLVR 两种范式,300 步,fp32 主权重;能力保持用 MMLU。少量 Llama 与 4B 的 v1 数据已作废。
- **工具**:
  - 逐矩阵梯度/更新的谱测量(v1–v2):在权重 SVD 基下分解梯度 G 与实际更新 H,信号/噪声分解,交叉样本估计。
  - 等范数子空间干预(v2–v3):把每步更新投影到谱方向(spectrum_matched)、同维随机方向(random_ext)、去掉谱方向(frame_matched)、精确保谱(exact_iso),再把范数匹配到 dense 步,并可乘 s_rel。
  - 功能步长核算(v3):单步 KL(8 步捕获,fp32 前向)、累计 KL 与权重位移(终点 ckpt)、MMLU 格式检查、lr 闸门、健康判据。
- **规模**:v3 共 16 + 3 + 4 个 RLVR run(A)、21 个 RLVR run(B)、20 个 SFT run(A),加 39 个 ckpt 的零训练诊断与 10 组 8 步捕获。A、B 两套硬件独立复现。

## 2. 发现了什么

**可靠的(两范式、多 seed、两套硬件一致)**

1. **功能步长混淆(唯一一条机理级结论)。** 等 Frobenius 范数的子空间投影更新与 dense 步几乎正交(cos ≈ 0.02);单步 KL 比 dense 小 2–4 个数量级(SFT 约 300 倍,RLVR 约 3000 倍)。因此"限制到某个子空间能保能力"的效果等价于把 lr 调小几十倍,不是子空间的功劳。
2. **权重的 SVD 基不特殊。** 更新限制在谱方向与限制在同维随机方向,任务指标与能力保持不可分(SFT 3 seed:+0.014/−0.001;RLVR 在 r 维真正推进的步长上:−0.026/−0.001,4 run)。
3. **等范数保谱更新与 dense 不可分。** frame_matched 对 full:SFT +0.015/+0.003;RLVR +0.012/−0.003(11 run)。去谱一半(exact_iso)因引擎缺陷作废,修复版重跑中。
4. **r 维约束不改善任务/能力折中。** SFT 上是另一个权衡点(GSM8K 低 0.03、MMLU 高 0.02,无一方占优);RLVR 上被 dense 严格占优(GSM8K 低 0.09,t ≈ −11,MMLU 相同),只是学得慢。
5. **健康 lr 是 lr×1 的十分之一**(SFT 1e-6、RLVR 2e-7),8 步捕获的功能步长提前预测命中;lr×1 是崩溃区。

**登记了但没有解释的**

- SFT 下 r 维更新的训练 loss 随步长单调下降(0.60→0.55→0.52),任务指标不动。
- RLVR 下等范数 r 维更新的累计 KL 只有 dense 的 1%,SFT 下有 60%;两范式对同一干预的功能响应差 60 倍。
- SFT 的累计 KL 对 lr 几乎不敏感(lr×1/30 到 ×1/3 都是 0.85–0.87),权重位移却差 5 倍。

**被推翻的**

- v1:credit-assignment 决定梯度谱几何、v1 H4 的 Spearman 相关——耦合假象(均值梯度信号能量 <1% 噪声)。
- v2:条件谱增益(开放谱方向有不可替代的收益)——不存在;"mn 维崩 MMLU"——崩溃区加格式假象。
- v3:C5(r 维约束改善折中)——阴性。

## 3. 本来提出了什么优化假设与方法,结果如何,有没有效果

| 版本 | 假设 | 方法 | 结果 | 效果 |
|---|---|---|---|---|
| v1 | 后训练梯度的谱 ordering 反映 credit assignment,可用来分配步长 | SSD 优化器(按谱位置缩放更新) | 谱 ordering 是耦合假象;bf16 主权重使训练结局作废 | **无**;方法前提不成立 |
| v2 | frame 更新可用时,开放谱方向有条件增益,可门控 | PGSU(投影梯度谱更新)+ 门控 | 谱字典 ≈ 随机字典,无独立价值;C3 门控删除 | **无** |
| v3 | r 维约束(谱或随机)在健康 lr 下改善折中 | 等范数子空间干预 + s_rel | 功能步长小两个量级;dense 调 lr 即可达到或超过 | **无**;作为实验手段有效,作为方法无收益 |
| v3 | 保谱/去谱在健康区与 dense 不可分(C4) | frame_matched / exact_iso 对照 | 保谱成立;去谱待修复版 | 是结论不是方法 |
| v3 | 8 步功能步长可预测健康 lr 档位(E-v3-0c) | 单步 KL 诊断 | 两次命中(SFT、RLVR) | **诊断工具**,不是训练方法 |
| v3 | 实验协议 | 随机基对照、功能步长匹配、lr 闸门、格式检查、SVD 精度核对、跨硬件独立样本 | 每一条都在本项目里抓到过真问题 | **方法论产出**,不改进训练 |

**结论:项目至今没有提出任何让后训练变好的方法。** 解决的问题是"为什么此前的谱几何方法看起来有效",答案是功能步长混淆。

## 6. 需要的实验与必须达到的预期效果

三条路线互斥,由用户选择。每条列出实验、规模、**必须达到的预期效果(达标线)**与**否决线**。

### 路线 A:就地收口(不需要新实验)

- 内容:等 exact_iso 修复版与 lr×1/30 补 seed 落地,写成 negative + protocol 短文。
- 达标线:无新增判据;C4 去谱一半的结果无论方向都如实写。
- 产出:一周内成文;分量不到主会,适合 workshop 或作为技术报告。
- 意义:把功能步长混淆、随机基对照、崩溃区、格式假象、SVD 数值坑写清楚,防止别人重蹈。

### 路线 B:给否定结论找到对手 —— 检验 SVD-based PEFT 的前提

**靶子**:一族已发表方法明确假设权重 SVD 基是特权坐标系:PiSSA(用主奇异向量初始化 LoRA)、SVFT / SVDiff(只训练奇异值)、spectral adapter 等。我们的 spectrum_matched 本质上是"只训奇异值"的等范数版本,random_ext 是它的随机基对照。

**主张**:这些方法的收益来自秩与有效步长,不来自基;并给出任何"子空间 PEFT"都应通过的两关检验协议(随机基对照 + 功能步长匹配)。

**实验(A 先花半天读清 PiSSA、SVFT、spectral adapter 的具体设定,确认我们的臂与它们的对应关系,再定最终清单)**:

| 编号 | 实验 | 规模 | 必须达到的预期效果(达标线) | 否决线 |
|---|---|---|---|---|
| B-1 | PiSSA、SVFT 按原实现(或最接近的等价实现)训练,各扫 lr 3 档 | 0.8B × GSM8K × {SFT, RLVR},每格 3 run | 每个方法找到健康 lr\*,并落在它自己的"任务 vs 能力"前沿上 | 某方法在任何 lr 下都不健康 → 该方法只进附录 |
| B-2 | 每个方法配同秩随机基对照(把奇异基换成随机正交基,其余不变) | 同上,每格 3 run | **达标:同秩随机基对照与原方法在 margin 内(GSM8K 0.03 / MMLU 0.02)**,即"基不特殊"在真实方法上成立 | 原方法显著优于随机基对照(≥ margin 且 3 run 一致)→ 主张反转:基确实特殊,论文改写为"何时特殊" |
| B-3 | 功能步长匹配:把每个方法与 dense 在相同单步 KL 下比较,而不是相同 lr 或相同范数 | 同上,用 8 步捕获定匹配点,再各 3 run | **达标:匹配功能步长后,方法对 dense 的"保能力"优势消失或缩到 margin 内** | 匹配后优势仍在 → 方法有基之外的真实收益,同样是可写结果 |
| B-4 | 泛化单元:第二模型(Qwen3.5-2B,RLVR)与第二任务(MATH,两范式),重复 B-1 到 B-3 的核心格 | 2B:12 run(A100);0.8B×MATH:24 run(MIG) | **达标:B-2 与 B-3 的结论在 ≥ 2 个新单元中的 ≥ 1 个上重复,且无反向显著结果** | 在两个新单元上都反向 → 结论限定为"0.8B/GSM8K" ,论文退回路线 A |
| B-5 | C4 去谱一半:exact_iso 修复版(已在跑) | 0.8B,RLVR 3 + SFT 2 | 与 dense 在 margin 内 → C4 完整 | 可分 → C4 改写为方向性结论(同样可写) |

**成文条件**:B-2 与 B-3 在 0.8B/GSM8K 两范式上达标,且 B-4 至少一个单元重复。此时论文的一句话是:"SVD-based PEFT 假设奇异基特殊;随机基对照与功能步长匹配表明它不特殊,收益来自秩与有效步长;我们给出检验协议。"有靶子、有工具、有跨单元证据。

**风险**:PiSSA/SVFT 在原设定下可能真的优于随机基(否决线触发)。那不是失败,是结论反转,论文改写为"基何时特殊",同样成立;但要接受主张不由我们预设。

**预算**:B-1 到 B-3 约 36 run(MIG,SFT 2 h / RLVR 5 h);B-4 约 36 run(A100 8 h / MIG);合计约 300 GPU 小时,A、B 各半,约 5 天 wall。

### 路线 C:转向功能步长核算 —— 后训练增量里有多少是承重的

**问题**:一次后训练的权重增量中,功能上承重的部分有多少、分布在哪些矩阵与方向?已有观察暗示答案极不均匀(RLVR r 维累计 KL 1% vs SFT 60%;SFT 位移涨 5 倍而 KL 不变)。

**潜在方法**:按功能贡献压缩或合并后训练增量(面向 delta 压缩、模型合并的受众),这是本项目工具链唯一可能长出正面方法的方向。

| 编号 | 实验 | 规模 | 必须达到的预期效果(达标线) | 否决线 |
|---|---|---|---|---|
| C-0 | **零训练可行性**:对现有 39 个 v3 终点 ckpt,逐矩阵把增量归零(或按奇异方向截断),测 KL 与 GSM8K/MMLU 的变化,画"保留比例 vs 功能保留"曲线 | 1 张卡 1 天 | **达标:去掉 ≥ 50% 的增量范数(按矩阵或方向)时 GSM8K 掉 ≤ 0.02 且 KL 保留 ≥ 80%**,即承重部分集中 | 承重均匀分布(曲线接近对角线)→ 没有可压缩结构,路线 C 终止 |
| C-1 | 承重结构的稳定性:跨 seed、跨 lr、跨范式,承重矩阵/方向是否一致 | 用现有 ckpt,零训练 | 承重集合跨 seed 重合度 ≥ 0.7 | 不稳定 → 只能做事后压缩,不能做事前预测 |
| C-2 | 方法:按功能贡献的增量压缩,对比幅值剪枝、低秩截断、随机剪枝 | 0.8B 两范式,再加一个模型 | **在相同压缩比下功能保留显著优于所有基线(≥ margin,3 run)** | 与幅值剪枝不可分 → 方法无增量价值 |
| C-3 | 泛化:第二模型、第二任务 | 同 B-4 的单元 | 达标同 C-2 | 同上 |

**成文条件**:C-0 达标是前提(否则一天内终止);C-2 达标才有正面方法。风险:这是换题,前两周只有机理分析,方法在后面;且 delta 压缩已有文献,需要在 C-2 前核对基线。
