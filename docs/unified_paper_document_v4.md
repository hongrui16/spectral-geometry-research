# 第一部分:现阶段工作总结

## 一、我们分析了什么,得到了什么

**问题是什么。** 大模型做后训练(SFT 或强化学习)时,权重矩阵会被更新。我们想知道:权重矩阵自带的一组"主方向"(把矩阵做 SVD 分解得到的方向)对训练来说是不是特殊的。具体问三件事:

1. 只沿这些主方向更新,和沿随便挑的一组方向更新,结果有没有区别?
2. 更新时保持矩阵的"谱"(各主方向的强弱)不变,或者故意不让它变,和正常训练比有没有区别?
3. 把更新限制在少数方向上,能不能做到"任务学得多、原有能力掉得少"?

**怎么分析的。** 三样工具:
- 把每一步的更新拆到权重的主方向上,看哪部分是信号、哪部分是噪声。
- 干预实验:每一步都把更新改造成四种版本之一(只留主方向、只留随机方向、去掉主方向、完全不改谱),然后把改造后的步子调到和正常训练一样长,再比较结果。
- 算"这一步到底让模型变了多少":用模型输出分布的变化量(KL)来衡量,而不是看权重数值变了多少。

**分析出来的东西。**

1. **最重要的一条:步子长短是假象。** 把更新限制到少数方向后,虽然权重上的步长调成和正常训练一样,但模型输出的实际变化只有正常训练的百分之一到千分之一。原因是被限制后的更新方向和正常更新几乎垂直。所以之前看到的"限制方向能保住能力",其实等于把学习率悄悄调小了几十倍,和方向本身没关系。
2. **主方向不特殊。** 只沿主方向更新和只沿随机方向更新,任务分数和能力保持都分不出差别。
3. **保持谱不变也不特殊。** 不改谱的更新和正常训练分不出差别。(故意去谱的那一组因为代码里的数值问题作废了,修好后在重做。)
4. **限制方向不能改善取舍。** SFT 上它只是换了一个取舍点(任务低一点、能力高一点);强化学习上它全面不如正常训练,只是学得慢。
5. **正常训练的健康学习率是原来常用值的十分之一。** SFT 和强化学习都是。用原来的值训练,模型会崩;之前看到的"能力崩到接近随机"一部分是崩溃,一部分是答题格式坏了导致的测量假象。

**看到了但没解释的。** 三件事:SFT 下限制方向的更新,训练损失在降但任务分数不动;强化学习下限制方向的更新几乎不改变模型输出(只有正常训练的百分之一),SFT 下却能到六成;SFT 下学习率差十倍,模型输出的总变化量几乎一样,但权重走的距离差五倍。

**被推翻的。** v1 说梯度的主方向排序反映了"哪些参数该负责",是测量耦合造成的假象。v2 说开放主方向有额外收益,不存在。v3 说限制方向能改善取舍,不能。

## 二、我们提出过什么优化方法,效果如何

| 版本 | 想法 | 做法 | 结果 |
|---|---|---|---|
| v1 | 按更新在主方向上的位置分配步长 | SSD 优化器 | 想法的前提被推翻,没效果,放弃 |
| v2 | 平时只更新非主方向,有条件时才开放主方向 | PGSU 加门控 | 主方向和随机方向一样,开放它没价值,放弃 |
| v3 | 把更新限制在少数方向上,并放大步长 | 等长度的方向限制 | 没收益,正常训练把学习率调好就能做到一样或更好 |
| v3 | 训练 8 步就预测健康学习率 | 看 8 步内模型输出的变化量 | 两次猜中,但它是个检查工具,不是训练方法 |
| v3 | 一套实验规范 | 随机方向对照、按输出变化量对齐步长、先找健康学习率、检查答题格式、检查 SVD 数值精度 | 防止别人掉坑,不改进训练 |

**一句话:三代方法没有一个在健康学习率下胜过正常训练。我们没有提出任何让后训练变好的方法。** 我们解决的是"为什么之前这类方法看起来有效",答案是步长假象。

## 三、实验结果

设定:Qwen3.5-0.8B,任务 GSM8K(数学题),SFT 和强化学习各训 300 步。任务分数看 GSM8K 准确率,能力保持看 MMLU 准确率。不训练的起点是 GSM8K 0.546、MMLU 0.483。下面的数字都是"GSM8K / MMLU"。

**先找健康学习率**

| | 常用值的 1/30 | 常用值的 1/10(选定) | 常用值的 1/3 |
|---|---|---|---|
| SFT | 0.390 / 0.461 健康 | **0.415 / 0.456** 健康 | 0.420 / 0.302 能力崩 |
| 强化学习 | 0.562 / 0.479 健康 | **0.646 / 0.471** 健康 | 0.699 / 0.457 不同随机种子差太多,能力压线 |

**主实验(都在选定的学习率上)**

| 更新方式 | SFT | 强化学习 |
|---|---|---|
| 正常训练 | 0.415 / 0.456 | 0.646 / 0.471 |
| 不改谱 | 0.400 / 0.454 | 0.634 / 0.473 |
| 故意去谱 | 作废,重做中 | 作废,重做中 |
| 只沿主方向 | 0.389 / 0.474 | 0.556 / 0.478 |
| 只沿随机方向 | 0.375 / 0.475 | 0.556 / 0.477 |

怎么读:
- 主方向和随机方向:SFT 差 0.014,强化学习差 0。分不出。
- 不改谱和正常训练:SFT 差 0.015,强化学习差 0.012。分不出(我们定的"算有差别"的门槛是 0.03)。
- 限制方向和正常训练:SFT 下任务低 0.03、能力高 0.02,是另一个取舍点;强化学习下任务低 0.09、能力一样,全面落后。
- 把限制方向的步长放大 3 倍、10 倍,或学习率调回常用值:SFT 下任务分数不动;强化学习下从 0.56 升到 0.59、0.62,还是不如正常训练的 0.646。

**辅助测量**

- 训练 8 步时,限制方向的更新让模型输出变化的量,只有正常训练的三百分之一(SFT)到三千分之一(强化学习);不改谱的更新和正常训练差不多。
- 训完 300 步,强化学习下限制方向的更新让模型总共只变了正常训练的 1%;SFT 下有 60%。
- 答题格式检查:健康学习率下所有模型格式正常;之前"能力崩到 0.24"的模型是格式坏了;SFT 用常用值的 1/3 训出来的模型是格式坏了加真的变差。
- 故意去谱那一组:实现里用的 GPU SVD 默认算法在单精度下误差有万分之一,每步重设谱时把这个误差当成更新加进去了,相当于每步注入四倍于正常更新的噪声,所以旧结果全部作废。换了高精度算法并把步长对齐后在重做。

**现在到了哪一步。** 手里有一组可靠的否定结论和一条"步长假象"的解释,范围是一个 0.8B 模型、一个任务、300 步。能写成一篇诚实的"我们试了、没用、原因是这个"的短文,分量到不了顶会主会。四个版本下来,"权重主方向"这个视角在每一层都没挖到东西。

# 第二部分:要达到顶会主会的水平,还需要哪些实验,要做出什么结果

## 0. 对目前结果的评估

**一句话:分析没有分析出让人耳目一新的问题,也没有提出任何有效的优化方法。**

- 分析里唯一新的东西是"步长假象"。它可靠,但它是拆穿一个错觉,不是发现一个新问题。其他结论全是"没区别、没用",没有一条会让读者觉得"原来如此"。三个没解释的现象有点意思,但没追出原因。
- 三代方法没有一个胜过正常训练。剩下的检查工具和实验规范是工具,不是方法。
- 现状:一条假象解释、一套规范、一组否定结论,零方法。

**审稿人会怎么看**

| 看什么 | 我们有什么 | 评价 |
|---|---|---|
| 新不新 | "主方向不特殊、限制方向没用、原因是步长假象" | 假象解释是新的;但结论是否定式的,而且现实里没人把更新锁在权重主方向上,**这个否定没有对手** |
| 有没有能用的东西 | 检查工具、实验规范 | 都不让训练变好。**没有方法** |
| 证据硬不硬 | 每个结论 2 到 6 次实验,差别都在门槛内 | 否定结论靠"分不出差别"证明,而两三个种子时统计检验根本没有区分力;强化学习在这个规模下换个种子就差 0.05,和门槛一样大 |
| 覆盖面 | 一个 0.8B 模型、一个任务、300 步 | "普遍不特殊"这种说法在一个点上立不住 |
| 和已有工作的关系 | 没和 LoRA、PiSSA、SVFT、正交化更新这些方法正面比过 | 审稿人第一个问题就是这个 |
| 可靠不可靠 | 崩溃区、格式假象、数值坑、换硬件不复现,都抓到了 | 这是最强的部分,但它是规范贡献,不是科学结论 |

**结论**:现在的结果是一篇可靠、诚实、但没有对手也没有方法的否定式短文。能进 workshop,到不了主会。差的不是实验数量,是两样东西之一:一个对手(让否定有意义),或一个正面方法(让读者能用)。而且四个版本的经验说明,继续在"权重主方向"这个视角下加模型、加任务,预期还是否定,不会改变论文的性质。

所以下面的实验分三类:补齐手头的(必须做,但不改变性质);给否定找一个对手(还在老视角下,上限是一篇"打靶"论文);换一个方向(唯一可能做出正面方法的)。每个实验都写清楚必须做出什么结果才算数,做不出就不写论文、不加实验。

## 1. 补齐手头的结论(必须做,不改变论文性质)

| 实验 | 规模 | 必须做出的结果 |
|---|---|---|
| 故意去谱那一组修好后重做(在跑) | 强化学习 3 次、SFT 2 次 | 和正常训练分不出差别(门槛 0.03 / 0.02)→ "不改谱、去谱都和正常训练一样"这句话完整;若分得出,如实写方向 |
| 强化学习 1/30 学习率补两次(在跑) | 2 次 | 健康学习率那张表补完整 |

## 2. 给否定结论找一个对手:检验"SVD 基特殊"这类方法的前提

现在的否定结论没有对手。但有一族已经发表的方法明确假设权重主方向是特殊的:PiSSA(用主方向初始化 LoRA)、SVFT 和 SVDiff(只训练主方向上的强弱)、各种 spectral adapter。我们的"只沿主方向更新"就是"只训主方向强弱"的等步长版本,"只沿随机方向"就是它的对照。

如果拿这些方法当靶子,论文的一句话变成:"这些方法假设主方向特殊;用随机方向对照和按输出变化量对齐步长两个检验,我们证明它不特殊,收益来自秩和实际步长;并给出任何这类方法都应通过的检验规范。"

| 实验 | 规模 | 必须做出的结果 | 做不出怎么办 |
|---|---|---|---|
| 把 PiSSA、SVFT 按原实现跑,每个扫三档学习率 | 0.8B,GSM8K,SFT 和强化学习各做,每格 3 次 | 每个方法都能找到健康学习率 | 找不到的方法放附录 |
| 给每个方法配一个"同秩随机方向"对照(主方向换成随机方向,其他不动) | 同上 | **对照和原方法分不出差别**,即"主方向不特殊"在真实方法上成立 | 原方法明显好于随机对照 → 结论反过来,论文改写成"主方向什么时候特殊",也能写 |
| 按输出变化量对齐步长后,再和正常训练比 | 同上 | **对齐后方法"保能力"的优势消失,或缩到门槛内** | 优势还在 → 方法有主方向之外的真实收益,也能写 |
| 换一个模型(Qwen3.5-2B,强化学习)和换一个任务(MATH,两种范式),重复上面两条 | 2B 12 次;0.8B 上 MATH 24 次 | **上面两条至少在一个新设定里重复,而且没有反向的显著结果** | 两个新设定都反向 → 结论只能限定在 0.8B 加 GSM8K,退回短文 |

能写论文的条件:随机对照和步长对齐两条在 0.8B 加 GSM8K 上两种范式都成立,并且在一个新设定里重复。大约 70 次训练、300 GPU 小时、两到三周。
和第一部分评估的关系:这条路还在老视角下,预期结果还是否定(主方向不特殊)。它能成文不是因为找到了新机制,而是因为否定有了对手和检验规范。上限是一篇"打靶"的实证论文。

## 3. 换一个方向:后训练改动里,真正起作用的部分有多少、在哪

问题:一次后训练把权重改了一大堆,其中真正影响模型输出的部分占多少、集中在哪些矩阵和方向上?已有的观察暗示很不均匀(强化学习下限制方向的更新只让模型变了 1%,SFT 下 60%;SFT 权重走五倍距离输出变化一样)。如果起作用的部分是集中的,就能做一个方法:按"对输出的贡献"压缩或合并后训练改动,面向做模型合并、改动压缩的人。这是我们手里的工具唯一可能长出正面方法的方向。

| 实验 | 规模 | 必须做出的结果 | 做不出怎么办 |
|---|---|---|---|
| C-0 可行性:拿现有 39 个训完的模型,逐个矩阵或逐个方向把改动去掉,看输出变化和分数掉多少 | 一张卡一天,不训练 | **去掉一半以上的改动量时,GSM8K 掉不超过 0.02、输出变化保留八成以上**(起作用的部分是集中的) | 均匀分布 → 这条路停 |
| C-1 起作用的部分换种子、换学习率、换范式稳不稳 | 用现有模型,不训练 | 起作用的矩阵集合跨种子重合七成以上 | 不稳 → 只能事后压缩,不能事前预测 |
| C-2 方法:按对输出的贡献压缩改动,对比按数值大小剪、低秩截断、随机剪 | 0.8B 两种范式,再加一个模型 | **同样的压缩比下,保留的效果明显好于所有对照(超过门槛,3 次一致)** | 和按数值大小剪分不出 → 方法没有额外价值 |
| C-3 换模型、换任务 | 同第 2 节的设定 | 同 C-2 | 同上 |

能写论文的条件:C-0 成立是前提(一天定生死),C-2 成立才有正面方法。三到四周。这是换题,而且改动压缩已经有文献,做 C-2 之前要先核对已有基线。

## 4. 建议

- 不管走哪条,先把第一部分对应的短文写起来,它是后面任何一条的基础。
- 先做 C-0(一天、不训练、用现有模型),同时花半天把第 2 节的靶子方法读清楚。两件事都不占训练用的 GPU。
- C-0 成立就走第 3 节(有可能做出方法);不成立就走第 2 节(有对手的否定)或止于短文。由用户决定。
