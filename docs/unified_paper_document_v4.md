# 第一部分:现阶段工作总结

## 一、分析

**分析的问题**:LLM 后训练(SFT、RLVR)的权重更新在权重奇异基(SVD 基)下有没有特殊结构;把更新限制到谱方向、随机方向、去掉谱方向、精确保谱,在匹配步长后,任务收益与能力保持有没有可测差别;子空间约束能不能改善"任务提升 vs 能力保持"的折中。

**分析的方法**:逐矩阵在权重 SVD 基下分解梯度与更新,做信号/噪声分解;等范数子空间干预(spectrum_matched、random_ext、frame_matched、exact_iso,范数匹配到 dense 步,可乘 s_rel);功能步长核算(单步 KL、累计 KL、权重位移);lr 闸门与健康判据;MMLU 格式检查。

**分析得到的结论**

1. **功能步长混淆。** 等范数子空间投影更新与 dense 步几乎正交(cos ≈ 0.02),单步 KL 比 dense 小 2–4 个数量级。"限制到子空间能保能力"等价于把 lr 调小几十倍,不是子空间的功劳。这是唯一一条机理级结论。
2. **权重的 SVD 基不特殊。** 更新限制在谱方向和限制在同维随机方向,结果不可分。
3. **等范数保谱更新与 dense 不可分。** 去谱一半因引擎缺陷作废,修复后重做。
4. **r 维约束不改善折中。** SFT 上是另一个权衡点,RLVR 上被 dense 严格占优,只是学得慢。
5. **健康 lr 是 lr×1 的十分之一**,两种范式都是;lr×1 是崩溃区,v2 的"mn 维崩 MMLU"是崩溃区加格式假象。

**没解释的现象**:SFT 下 r 维更新 loss 随步长下降而任务指标不动;RLVR 下 r 维累计 KL 只有 dense 的 1%,SFT 有 60%;SFT 累计 KL 对 lr 不敏感而位移差 5 倍。

**被推翻的**:v1 credit-assignment 决定谱几何(耦合假象);v2 条件谱增益(不存在);v3 C5 r 维约束改善折中(阴性)。

## 二、优化方法

| 版本 | 假设 | 方法 | 结果 |
|---|---|---|---|
| v1 | 梯度的谱 ordering 反映 credit assignment,可按谱位置分配步长 | SSD 优化器 | 前提被推翻,无效果,放弃 |
| v2 | frame 更新可用时,开放谱方向有条件增益,可门控 | PGSU + 门控 | 谱字典 ≈ 随机字典,无独立价值,放弃 |
| v3 | r 维约束(谱或随机)在健康 lr 下改善折中 | 等范数子空间干预 + s_rel | 无收益;dense 调 lr 即可达到或超过 |
| v3 | 8 步功能步长可预测健康 lr 档位 | 单步 KL 诊断 | 两次命中;是诊断工具,不是训练方法 |
| v3 | 实验协议 | 随机基对照、功能步长匹配、lr 闸门、格式检查、SVD 精度核对 | 方法论产出,不改进训练 |

**没有提出任何让后训练变好的方法。** 解决的是"为什么此前的谱几何方法看起来有效",答案是功能步长混淆。

## 三、实验结果

设定:Qwen3.5-0.8B,GSM8K,SFT 与 RLVR 各 300 步,fp32;能力保持用 MMLU;base 0.546 / 0.483。

**闸门(健康 lr)**

| 范式 | lr×1/30 | lr×1/10 = lr\* | lr×1/3 |
|---|---|---|---|
| SFT | 0.390 / 0.461 健康 | **0.415 / 0.456** 健康 | 0.420 / 0.302 MMLU 崩 |
| RLVR | 0.562 / 0.479 健康 | **0.646 / 0.471** 健康 | 0.699 / 0.457 seed 离散超标、MMLU 压线 |

**主结果(lr\*,GSM8K / MMLU)**

| 更新 | 维度 | SFT | RLVR |
|---|---|---|---|
| full(dense) | mn | 0.415 / 0.456 | 0.646 / 0.471 |
| frame_matched(保谱) | mn | 0.400 / 0.454 | 0.634 / 0.473 |
| exact_iso(去谱) | mn | 作废,重做中 | 作废,重做中 |
| spectrum_matched(谱字典) | r | 0.389 / 0.474 | 0.556 / 0.478 |
| random_ext(随机字典) | r | 0.375 / 0.475 | 0.556 / 0.477 |

- 谱字典 vs 随机字典:SFT +0.014 / −0.001;RLVR 0.000 / +0.001(lr×1 上 −0.026)→ 不可分。
- 保谱 vs dense:SFT +0.015 / +0.003;RLVR +0.012 / −0.003 → 不可分。
- r 维 vs dense:SFT GSM8K 低 0.03、MMLU 高 0.02(另一个权衡点);RLVR GSM8K 低 0.09、MMLU 相同(dense 占优)。
- s_rel 1→3→10 与 lr×1:SFT 的 r 维任务指标不动(loss 0.60→0.55→0.52 在动);RLVR 的 r 维 GSM8K 0.56→0.56→0.59,lr×1 0.62,仍在 dense 之下。

**诊断**

- 单步 KL(8 步,等范数):r 维投影更新比 dense 小 SFT 约 300 倍、RLVR 约 3000 倍;保谱与 dense 同量级。
- 累计 KL(300 步终点):RLVR r 维为 dense 的 1%,s_rel 10 或 lr×1 为 5–25%;SFT r 维为 dense 的 60%。SFT 累计 KL 在 lr×1/30 到 ×1/3 间都是 0.85–0.87。
- MMLU 格式:健康区无格式假象;v2 lr×1 dense 的 0.24 是格式假象;SFT lr×1/3 的 0.30 是格式漂移加真实损失。
- exact_iso:CUDA 默认 SVD 求解器 fp32 误差 1e-4,逐步钉谱注入 4 倍 dense 步的噪声,旧结果全部作废;改用 gesvda 并加等范数匹配后重做。

**达到的地步**:一组可靠的否定结论加一条混淆机理,覆盖一个 0.8B 模型、一个任务、300 步;能写成 negative + protocol 短文,分量到不了主会;谱几何透镜在四个层面上都没切到东西。

# 第二部分:若要达到顶会主会投稿水平,还需要哪些实验,要达到什么预期效果

## 0. 对目前结果的评估

**按审稿标准逐项打分**

| 维度 | 现状 | 评估 |
|---|---|---|
| 主张的新颖性 | "SVD 基不特殊、子空间约束不占优、原因是功能步长混淆" | 混淆机理是新的、可靠的;但主张是否定式,且实践中没人把更新锁进权重奇异子空间,**没有对手** |
| 正面贡献 | 诊断工具、实验协议 | 都不改进训练;诊断在 3 档 lr 里中 1 档,说服力弱。**没有方法** |
| 证据强度 | 每个结论 2–6 个 run,margin 内不可分 | 否定结论用"不可分"证明,2–3 seed 下 |t|<2 从不起作用,实际是点估计加 margin;RLVR 在此规模 seed 离散 0.05,与 margin 同量级 |
| 覆盖面 | 一个 0.8B、一个任务(GSM8K)、300 步 | 普遍性主张在一个点上不能成立 |
| 与文献的关系 | 未与 LoRA、PiSSA、SVFT、正交化更新等正面比较 | 审稿人第一个问题就是"和这些有什么关系" |
| 可靠性与诚实度 | 崩溃区、格式假象、SVD 数值坑、跨硬件不复现都抓到并登记 | 这是现有工作最强的部分,但它是 protocol 贡献,不是科学结论 |

**结论**:现有结果是一篇**可靠、诚实、但没有对手也没有方法的否定式短文**。它能进 workshop 或作为技术报告,到不了主会。差的不是 run 数,是两样东西:一个对手(让否定有意义)或一个正面方法(让读者能用)。四个版本的模式还说明,谱几何这个透镜本身在每一层都切不到东西,单纯在同一透镜下补规模、补任务,预期仍是否定,不会改变论文性质。

**因此下面的实验分三类**:补齐现有结论(必须做,但不改变性质);给否定找对手(仍在同一透镜下,上限是"打靶"实证论文);换题到可能长出正面方法的方向。每个实验按"必须达到的预期效果"写;达不到就不成文,不追加。

## 1. 补齐现有结论(无论哪条路都要做)

| 实验 | 规模 | 必须达到的预期效果 |
|---|---|---|
| exact_iso 修复版(在跑) | RLVR 3 seed + SFT 2 seed | 与 dense 在 margin 内(GSM8K 0.03 / MMLU 0.02)→ C4"保谱与去谱都 ≈ dense"完整;可分则如实写方向 |
| RLVR lr×1/30 补 seed(在跑) | 2 run | 与 B 的 2 run 合并为 4,闸门表完整 |

## 2. 给否定结论一个对手:检验 SVD-based PEFT 的前提

现有结论没有对手。有对手的版本是:PiSSA(主奇异向量初始化 LoRA)、SVFT / SVDiff(只训奇异值)等方法明确假设 SVD 基特殊;我们的 spectrum_matched 就是"只训奇异值"的等范数版本,random_ext 是它的随机基对照。

| 实验 | 规模 | 必须达到的预期效果 | 达不到时 |
|---|---|---|---|
| PiSSA、SVFT 按原实现,扫 lr 3 档 | 0.8B × GSM8K × {SFT, RLVR},每格 3 run | 每个方法有健康 lr\*,落在自己的任务/能力前沿上 | 不健康的方法进附录 |
| 同秩随机基对照 | 同上 | **随机基对照与原方法在 margin 内**(基不特殊在真实方法上成立) | 原方法显著优于随机基 → 结论反转为"基何时特殊",也可写 |
| 功能步长匹配:方法与 dense 在同单步 KL 下比较 | 同上 | **匹配后方法对 dense 的保能力优势消失或缩到 margin 内** | 优势仍在 → 方法有基之外的真实收益,可写 |
| 第二模型(Qwen3.5-2B,RLVR)与第二任务(MATH,两范式) | 2B 12 run(A100);0.8B×MATH 24 run(MIG) | **以上两条在 ≥ 1 个新单元重复,且无反向显著结果** | 两个单元都反向 → 结论限定 0.8B/GSM8K,退回短文 |

成文条件:随机基对照与功能步长匹配两条在 0.8B/GSM8K 两范式上达标,且一个新单元重复。约 70 run、300 GPU 小时、2–3 周。
**与第一部分判断的关系**:这条路仍在谱几何透镜下,预期结果仍是否定(基不特殊);它能成文的原因不是找到了正面机制,而是否定有了对手和检验协议。上限是一篇"打靶"的实证论文。

## 3. 换题:后训练增量的功能承重核算(唯一可能长出正面方法的方向)

问题:一次后训练的权重增量中,功能上承重的部分有多少、在哪些矩阵和方向。现有观察(RLVR r 维累计 KL 1% vs SFT 60%;SFT 位移涨 5 倍 KL 不变)暗示极不均匀。方法目标:按功能贡献压缩或合并后训练增量。

| 实验 | 规模 | 必须达到的预期效果 | 达不到时 |
|---|---|---|---|
| C-0 零训练可行性:对 39 个 v3 终点 ckpt 逐矩阵/逐方向去掉增量,测 KL 与 GSM8K/MMLU | 1 张卡 1 天 | **去掉 ≥ 50% 增量范数时 GSM8K 掉 ≤ 0.02 且 KL 保留 ≥ 80%**(承重集中) | 承重均匀 → 此路终止 |
| C-1 承重结构跨 seed / lr / 范式的稳定性 | 现有 ckpt,零训练 | 承重集合跨 seed 重合度 ≥ 0.7 | 不稳定 → 只能事后压缩 |
| C-2 方法:按功能贡献压缩增量,对比幅值剪枝、低秩截断、随机剪枝 | 0.8B 两范式 + 1 个模型 | **同压缩比下功能保留显著优于所有基线(≥ margin,3 run)** | 与幅值剪枝不可分 → 无增量价值 |
| C-3 第二模型、第二任务 | 同 §2 单元 | 同 C-2 | 同上 |

成文条件:C-0 达标是前提(一天定生死),C-2 达标才有正面方法。3–4 周;需先核对 delta 压缩已有文献的基线。

## 4. 建议

- 无论如何先写第一部分对应的短文(negative + protocol),它是任何后续的基础。
- C-0 一天、零训练、用现有 ckpt,先做;同时 A 半天读清 §2 的靶子方法。两件事都不占训练 GPU。
- C-0 达标则走 §3(有正面方法的可能);否决则走 §2(有对手的否定)或止于短文。由用户决定。
