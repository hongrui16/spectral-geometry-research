# 第一部分:现阶段工作总结

## 一、我们分析了什么,得到了什么

**问题是什么。** 大模型做后训练(SFT 或强化学习)时,权重矩阵会被更新。我们想知道:权重矩阵自带的一组"主方向"(把矩阵做 SVD 分解得到的方向)对训练来说是不是特殊的。具体问三件事:

1. 只沿这些主方向更新,和沿随便挑的一组方向更新,结果有没有区别?
2. 更新时保持矩阵的"谱"(各主方向的强弱)不变,或者故意不让它变,和正常训练比有没有区别?
3. 把更新限制在少数方向上,能不能做到"任务学得多、原有能力掉得少"?

**怎么分析的。** 三样工具:
- 把每一步的更新拆到权重的主方向上,看哪部分是信号、哪部分是噪声。
- 干预实验:每一步都把更新改造成四种版本之一(只留主方向、只留随机方向、去掉主方向、完全不改谱),然后把改造后的步子调到和正常训练一样长,再比较结果。
- 算"这一步到底让模型变了多少":用模型输出分布的变化量(KL)来衡量,而不是看权重数值变了多少。

**分析出来的东西。**

1. **最重要的一条:步子长短是假象。** 把更新限制到少数方向后,虽然权重上的步长调成和正常训练一样,但模型输出的实际变化只有正常训练的百分之一到千分之一。原因是被限制后的更新方向和正常更新几乎垂直。所以之前看到的"限制方向能保住能力",其实等于把学习率悄悄调小了几十倍,和方向本身没关系。
2. **主方向不特殊。** 只沿主方向更新和只沿随机方向更新,任务分数和能力保持都分不出差别。
3. **保持谱不变也不特殊。** 不改谱的更新和正常训练分不出差别。(故意去谱的那一组因为代码里的数值问题作废了,修好后在重做。)
4. **限制方向不能改善取舍。** SFT 上它只是换了一个取舍点(任务低一点、能力高一点);强化学习上它全面不如正常训练,只是学得慢。
5. **正常训练的健康学习率是原来常用值的十分之一。** SFT 和强化学习都是。用原来的值训练,模型会崩;之前看到的"能力崩到接近随机"一部分是崩溃,一部分是答题格式坏了导致的测量假象。

**看到了但没解释的。** 三件事:SFT 下限制方向的更新,训练损失在降但任务分数不动;强化学习下限制方向的更新几乎不改变模型输出(只有正常训练的百分之一),SFT 下却能到六成;SFT 下学习率差十倍,模型输出的总变化量几乎一样,但权重走的距离差五倍。

**被推翻的。** v1 说梯度的主方向排序反映了"哪些参数该负责",是测量耦合造成的假象。v2 说开放主方向有额外收益,不存在。v3 说限制方向能改善取舍,不能。

## 二、我们提出过什么优化方法,效果如何

| 版本 | 想法 | 做法 | 结果 |
|---|---|---|---|
| v1 | 按更新在主方向上的位置分配步长 | SSD 优化器 | 想法的前提被推翻,没效果,放弃 |
| v2 | 平时只更新非主方向,有条件时才开放主方向 | PGSU 加门控 | 主方向和随机方向一样,开放它没价值,放弃 |
| v3 | 把更新限制在少数方向上,并放大步长 | 等长度的方向限制 | 没收益,正常训练把学习率调好就能做到一样或更好 |
| v3 | 训练 8 步就预测健康学习率 | 看 8 步内模型输出的变化量 | 两次猜中,但它是个检查工具,不是训练方法 |
| v3 | 一套实验规范 | 随机方向对照、按输出变化量对齐步长、先找健康学习率、检查答题格式、检查 SVD 数值精度 | 防止别人掉坑,不改进训练 |

**一句话:三代方法没有一个在健康学习率下胜过正常训练。我们没有提出任何让后训练变好的方法。** 我们解决的是"为什么之前这类方法看起来有效",答案是步长假象。

## 三、实验结果

设定:Qwen3.5-0.8B,任务 GSM8K(数学题),SFT 和强化学习各训 300 步。任务分数看 GSM8K 准确率,能力保持看 MMLU 准确率。不训练的起点是 GSM8K 0.546、MMLU 0.483。下面的数字都是"GSM8K / MMLU"。

**先找健康学习率**

| | 常用值的 1/30 | 常用值的 1/10(选定) | 常用值的 1/3 |
|---|---|---|---|
| SFT | 0.390 / 0.461 健康 | **0.415 / 0.456** 健康 | 0.420 / 0.302 能力崩 |
| 强化学习 | 0.562 / 0.479 健康 | **0.646 / 0.471** 健康 | 0.699 / 0.457 不同随机种子差太多,能力压线 |

**主实验(都在选定的学习率上)**

| 更新方式 | SFT | 强化学习 |
|---|---|---|
| 正常训练 | 0.415 / 0.456 | 0.646 / 0.471 |
| 不改谱 | 0.400 / 0.454 | 0.634 / 0.473 |
| 故意去谱 | 作废,重做中 | 作废,重做中 |
| 只沿主方向 | 0.389 / 0.474 | 0.556 / 0.478 |
| 只沿随机方向 | 0.375 / 0.475 | 0.556 / 0.477 |

怎么读:
- 主方向和随机方向:SFT 差 0.014,强化学习差 0。分不出。
- 不改谱和正常训练:SFT 差 0.015,强化学习差 0.012。分不出(我们定的"算有差别"的门槛是 0.03)。
- 限制方向和正常训练:SFT 下任务低 0.03、能力高 0.02,是另一个取舍点;强化学习下任务低 0.09、能力一样,全面落后。
- 把限制方向的步长放大 3 倍、10 倍,或学习率调回常用值:SFT 下任务分数不动;强化学习下从 0.56 升到 0.59、0.62,还是不如正常训练的 0.646。

**辅助测量**

- 训练 8 步时,限制方向的更新让模型输出变化的量,只有正常训练的三百分之一(SFT)到三千分之一(强化学习);不改谱的更新和正常训练差不多。
- 训完 300 步,强化学习下限制方向的更新让模型总共只变了正常训练的 1%;SFT 下有 60%。
- 答题格式检查:健康学习率下所有模型格式正常;之前"能力崩到 0.24"的模型是格式坏了;SFT 用常用值的 1/3 训出来的模型是格式坏了加真的变差。
- 故意去谱那一组:实现里用的 GPU SVD 默认算法在单精度下误差有万分之一,每步重设谱时把这个误差当成更新加进去了,相当于每步注入四倍于正常更新的噪声,所以旧结果全部作废。换了高精度算法并把步长对齐后在重做。

**现在到了哪一步。** 手里有一组可靠的否定结论和一条"步长假象"的解释,范围是一个 0.8B 模型、一个任务、300 步。能写成一篇诚实的"我们试了、没用、原因是这个"的短文,分量到不了顶会主会。四个版本下来,"权重主方向"这个视角在每一层都没挖到东西。

# 第二部分:改进方案

## 0. 对目前结果的评估

**一句话:分析没有分析出让人耳目一新的问题,也没有提出任何有效的优化方法。**

- 分析里唯一新的东西是"步长假象"。它可靠,但它是拆穿一个错觉,不是发现一个新问题。其他结论全是"没区别、没用"。
- 三代方法没有一个胜过正常训练。剩下的检查工具和实验规范是工具,不是方法。
- 现状:一条假象解释、一套规范、一组否定结论,零方法。这样的结果只能写短文,到不了主会。

**主会需要的是一个能用的方法**:在同样的任务分数下能力掉得更少,或者同样的能力损失下任务学得更多,而且换个模型、换个任务还成立。再做多少分析实验都换不来这个。所以第二部分只写一件事:从我们的分析里能推出什么方法,怎么验证,必须做出什么结果。

## 1. 分析里能推出方法的线索

我们的结论大多是否定的,但有三条是正面线索:

1. **权重"白走"的部分伤能力。** SFT 下学习率从常用值的 1/30 提到 1/3,模型输出的总变化量几乎不变(0.85 到 0.87),权重走的距离却差五倍,能力从 0.461 掉到 0.302。也就是说,高学习率多走的那些路对任务没贡献,却把能力走丢了。
2. **各个矩阵的"效率"差二十倍。** 同样长的一步,不同矩阵引起的输出变化相差 0.26 到 5.2 倍(v2 的 A5 测量)。这说明"一刀切"的学习率对有些矩阵太大、对有些太小。
3. **训练 8 步就能测出步子的实际效果。** 8 步探针预测健康学习率两次命中。这个探针便宜(几分钟),可以在训练中反复用。

把三条合起来:**控制每个矩阵"对输出真正有效"的步长,而不是控制权重上的步长**,理论上能少走白路、少丢能力。这是我们的分析唯一能直接推出的方法。

## 2. 方法一(主线):按矩阵的功能效率调步长

**做法。**
- 每隔 k 步(比如 50 步),用探针测每个矩阵当前"单位步长引起多少输出变化"(效率)。
- 给每个矩阵一个步长倍率:效率低的矩阵把步长缩小(它的更新大多是白走),效率高的保持或略放大。
- 整体上把每一步引起的输出总变化量控制在一个目标值(可以理解为在"输出空间"里设一个信任区域,而不是在权重空间里设学习率)。
- 目标值扫三档,对应"保守、中等、激进"。

**要验证什么。** 它画出来的"任务分数 vs 能力保持"曲线,能不能整体压过正常训练调学习率画出来的曲线。

**实验。**

| 步骤 | 内容 | 规模 |
|---|---|---|
| 1 | 实现:探针 + 每矩阵倍率 + 总变化量控制,先在 8 步小跑上确认倍率和总变化量按预期生效 | 一天,一张卡 |
| 2 | 0.8B + GSM8K,SFT 和强化学习各扫三档目标值,每档 3 次 | 18 次训练 |
| 3 | 对照就是已经有的正常训练三档学习率曲线(不用重跑) | 0 |
| 4 | 换一个模型(Qwen3.5-2B)和一个任务(MATH),重复步骤 2 的最优两档 | 约 24 次训练 |

**必须做出的结果。**
- 在 0.8B + GSM8K 上:同样的 GSM8K 分数下,MMLU 比正常训练曲线高至少 0.02;或同样的 MMLU 下 GSM8K 高至少 0.03。3 次一致,两种范式至少一种成立。
- 换模型或换任务后同样成立至少一个。
- 达到这两条,论文就有了:一个方法、一个解释它为什么有效的机理(白走伤能力)、跨设定的证据。

**做不出怎么办。** 如果曲线和正常训练重合,说明"白走的路"并不伤能力,或者伤能力的部分不是探针能抓到的;方法失败,停止,回到短文。不追加实验去救。

**风险。** 探针每 50 步做一次,开销约训练时间的 5%;每矩阵倍率会不会让训练不稳,要在步骤 1 看。类似的想法(自然梯度、信任区域)在强化学习里有,但按矩阵在函数空间控制后训练的步长,我们没看到过,写作时要核对文献。

## 3. 方法二(顺带):不用扫描,直接定学习率

**做法。** 训练前跑 8 步探针,把学习率定到"每步输出变化量等于已知的健康值"。这是把"两次猜中"变成一个正式的工具。

**实验。** 在 2B 和 MATH 上不扫描,直接用探针定的学习率训一次,再和扫描出来的最优学习率比。

**必须做出的结果。** 探针定的学习率落在健康区,分数和扫描出的最优值差不超过门槛。做到了就是一个省六次训练的实用工具,放进方法一的论文里当附加贡献;做不到就删掉。

## 4. 方法三(备选,换题):按对输出的贡献压缩后训练改动

**依据。** 强化学习下限制方向的更新只让模型变了 1%,SFT 下 60%;SFT 权重走五倍距离输出变化一样。说明后训练改动里真正起作用的部分可能很集中。

**做法。** 训完以后,按每个矩阵或每个方向对输出的贡献,把不起作用的改动去掉,得到更小的改动量,给模型合并和改动压缩用。

**先做一天预检。** 用现有 39 个训完的模型,逐个矩阵或方向去掉改动,看分数和输出变化。**必须做出:去掉一半以上改动量时 GSM8K 掉不超过 0.02、输出变化保留八成以上。** 做不到就不做这条。做到了再和"按数值大小剪、低秩截断、随机剪"三种对照比,必须明显好于所有对照才算方法。

这条是换题,只在方法一失败或用户决定换方向时启动。

## 5. 顺序、时间与分工

- 第 1 周:方法一步骤 1 到 2(0.8B + GSM8K,18 次);方法三的一天预检并行做。
- 第 2 周:方法一步骤 4(换模型、换任务);方法二顺带在同一批设定上验证。
- 第 3 周:出裁决;成立则写方法论文,不成立则写短文收口。
- 分工:A 实现方法一和方法二,跑 0.8B;B 跑 2B;两边交付格式同 v3。
- 停止条件:方法一在 0.8B + GSM8K 上两种范式都做不出来,立即停,不换模型去救。
