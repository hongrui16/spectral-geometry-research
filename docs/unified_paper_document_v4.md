# 第一部分:现阶段总结

## 一、分析发现了什么

**可靠的(两种范式、多 seed、A/B 两套硬件一致)**

1. **功能步长混淆。** 等范数子空间投影更新与 dense 步几乎正交(cos ≈ 0.02),单步 KL 比 dense 小 2–4 个数量级。"限制到子空间能保能力"等价于把 lr 调小几十倍,不是子空间的功劳。这是唯一一条机理级结论。
2. **权重的 SVD 基不特殊。** 更新限制在谱方向和限制在同维随机方向,结果不可分。
3. **等范数保谱更新与 dense 不可分。** 去谱一半因引擎缺陷作废,修复版在跑。
4. **r 维约束不改善折中。** SFT 上是另一个权衡点,RLVR 上被 dense 严格占优,只是学得慢。
5. **健康 lr 是 lr×1 的十分之一**,两种范式都是;lr×1 是崩溃区,v2 的"mn 维崩 MMLU"是崩溃区加格式假象。

**登记了但没解释的**

- SFT 下 r 维更新 loss 随步长下降而任务指标不动。
- RLVR 下 r 维累计 KL 只有 dense 的 1%,SFT 有 60%。
- SFT 累计 KL 对 lr 不敏感而位移差 5 倍。

**被推翻的**

- v1:credit-assignment 决定谱几何(耦合假象)。
- v2:条件谱增益(不存在)。
- v3:C5(阴性)。

## 二、提出的优化方法解决了什么

- **SSD / PGSU 优化器(v1–v2)**:前提被推翻,没解决任何问题,已放弃。
- **等范数子空间干预(v2–v3)**:作为实验手段有效,作为方法无收益,dense 调 lr 就能达到或超过。
- **功能步长诊断**:8 步捕获预测健康 lr 档位,两次命中。是诊断工具,不是训练方法。
- **实验协议**(随机基对照、功能步长匹配、lr 闸门、格式检查、SVD 精度核对、跨硬件独立样本):方法论产出,防止别人掉坑,不改进训练。

**严格地说:没有提出任何让后训练变好的方法。** 解决的是"为什么此前的谱几何方法看起来有效",答案是混淆。

## 三、达到了什么地步

- 实验:v3 计划全部完成,A、B 一致,数字全部登记;exact_iso 修复版和 lr×1/30 补 seed 在跑。
- 结论:一组可靠的否定结论加一条混淆机理,覆盖一个 0.8B 模型、一个任务、300 步。
- 论文:能写成一篇诚实的 negative + protocol 短文,分量到不了主会。
- 项目:谱几何这个透镜在四个层面上都没切到东西,继续在同一透镜下加规模不会改变性质。

# 第二部分:若要达到顶会主会投稿水平,还需要哪些实验,要达到什么预期效果

前提判断:主会论文需要 (a) 一个有对手的主张或一个正面方法,(b) 跨模型跨任务的证据。现有结果两者都没有。下面的实验按"必须达到的预期效果"写;达不到就不成文,不追加。

## 1. 补齐现有结论(无论哪条路都要做)

| 实验 | 规模 | 必须达到的预期效果 |
|---|---|---|
| exact_iso 修复版(在跑) | RLVR 3 seed + SFT 2 seed | 与 dense 在 margin 内(GSM8K 0.03 / MMLU 0.02)→ C4"保谱与去谱都 ≈ dense"完整;可分则如实写方向 |
| RLVR lr×1/30 补 seed(在跑) | 2 run | 与 B 的 2 run 合并为 4,闸门表完整 |

## 2. 给否定结论一个对手:检验 SVD-based PEFT 的前提

现有结论没有对手。有对手的版本是:PiSSA(主奇异向量初始化 LoRA)、SVFT / SVDiff(只训奇异值)等方法明确假设 SVD 基特殊;我们的 spectrum_matched 就是"只训奇异值"的等范数版本,random_ext 是它的随机基对照。

| 实验 | 规模 | 必须达到的预期效果 | 达不到时 |
|---|---|---|---|
| PiSSA、SVFT 按原实现,扫 lr 3 档 | 0.8B × GSM8K × {SFT, RLVR},每格 3 run | 每个方法有健康 lr\*,落在自己的任务/能力前沿上 | 不健康的方法进附录 |
| 同秩随机基对照 | 同上 | **随机基对照与原方法在 margin 内**(基不特殊在真实方法上成立) | 原方法显著优于随机基 → 结论反转为"基何时特殊",也可写 |
| 功能步长匹配:方法与 dense 在同单步 KL 下比较 | 同上 | **匹配后方法对 dense 的保能力优势消失或缩到 margin 内** | 优势仍在 → 方法有基之外的真实收益,可写 |
| 第二模型(Qwen3.5-2B,RLVR)与第二任务(MATH,两范式) | 2B 12 run(A100);0.8B×MATH 24 run(MIG) | **以上两条在 ≥ 1 个新单元重复,且无反向显著结果** | 两个单元都反向 → 结论限定 0.8B/GSM8K,退回短文 |

成文条件:随机基对照与功能步长匹配两条在 0.8B/GSM8K 两范式上达标,且一个新单元重复。约 70 run、300 GPU 小时、2–3 周。
**与第一部分判断的关系**:这条路仍在谱几何透镜下,预期结果仍是否定(基不特殊);它能成文的原因不是找到了正面机制,而是否定有了对手和检验协议。上限是一篇"打靶"的实证论文。

## 3. 换题:后训练增量的功能承重核算(唯一可能长出正面方法的方向)

问题:一次后训练的权重增量中,功能上承重的部分有多少、在哪些矩阵和方向。现有观察(RLVR r 维累计 KL 1% vs SFT 60%;SFT 位移涨 5 倍 KL 不变)暗示极不均匀。方法目标:按功能贡献压缩或合并后训练增量。

| 实验 | 规模 | 必须达到的预期效果 | 达不到时 |
|---|---|---|---|
| C-0 零训练可行性:对 39 个 v3 终点 ckpt 逐矩阵/逐方向去掉增量,测 KL 与 GSM8K/MMLU | 1 张卡 1 天 | **去掉 ≥ 50% 增量范数时 GSM8K 掉 ≤ 0.02 且 KL 保留 ≥ 80%**(承重集中) | 承重均匀 → 此路终止 |
| C-1 承重结构跨 seed / lr / 范式的稳定性 | 现有 ckpt,零训练 | 承重集合跨 seed 重合度 ≥ 0.7 | 不稳定 → 只能事后压缩 |
| C-2 方法:按功能贡献压缩增量,对比幅值剪枝、低秩截断、随机剪枝 | 0.8B 两范式 + 1 个模型 | **同压缩比下功能保留显著优于所有基线(≥ margin,3 run)** | 与幅值剪枝不可分 → 无增量价值 |
| C-3 第二模型、第二任务 | 同 §2 单元 | 同 C-2 | 同上 |

成文条件:C-0 达标是前提(一天定生死),C-2 达标才有正面方法。3–4 周;需先核对 delta 压缩已有文献的基线。
