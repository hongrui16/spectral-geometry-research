# 第一部分:现阶段工作总结

## 一、我们分析了什么,得到了什么

**问题是什么。** 大模型做后训练(SFT 或强化学习)时,权重矩阵会被更新。我们想知道:权重矩阵自带的一组"主方向"(把矩阵做 SVD 分解得到的方向)对训练来说是不是特殊的。具体问三件事:

1. 只沿这些主方向更新,和沿随便挑的一组方向更新,结果有没有区别?
2. 更新时保持矩阵的"谱"(各主方向的强弱)不变,或者故意不让它变,和正常训练比有没有区别?
3. 把更新限制在少数方向上,能不能做到"任务学得多、原有能力掉得少"?

**怎么分析的。** 三样工具:
- 把每一步的更新拆到权重的主方向上,看哪部分是信号、哪部分是噪声。
- 干预实验:每一步都把更新改造成四种版本之一(只留主方向、只留随机方向、去掉主方向、完全不改谱),然后把改造后的步子调到和正常训练一样长,再比较结果。
- 算"这一步到底让模型变了多少":用模型输出分布的变化量(KL)来衡量,而不是看权重数值变了多少。

**分析出来的东西。**

1. **最重要的一条:步子长短是假象。** 把更新限制到少数方向后,虽然权重上的步长调成和正常训练一样,但模型输出的实际变化只有正常训练的百分之一到千分之一。原因是被限制后的更新方向和正常更新几乎垂直。所以之前看到的"限制方向能保住能力",其实等于把学习率悄悄调小了几十倍,和方向本身没关系。
2. **主方向不特殊。** 只沿主方向更新和只沿随机方向更新,任务分数和能力保持都分不出差别。
3. **保持谱不变也不特殊。** 不改谱的更新和正常训练分不出差别。(故意去谱的那一组因为代码里的数值问题作废了,修好后在重做。)
4. **限制方向不能改善取舍。** SFT 上它只是换了一个取舍点(任务低一点、能力高一点);强化学习上它全面不如正常训练,只是学得慢。
5. **正常训练的健康学习率是原来常用值的十分之一。** SFT 和强化学习都是。用原来的值训练,模型会崩;之前看到的"能力崩到接近随机"一部分是崩溃,一部分是答题格式坏了导致的测量假象。

**看到了但没解释的。** 三件事:SFT 下限制方向的更新,训练损失在降但任务分数不动;强化学习下限制方向的更新几乎不改变模型输出(只有正常训练的百分之一),SFT 下却能到六成;SFT 下学习率差十倍,模型输出的总变化量几乎一样,但权重走的距离差五倍。

**被推翻的。** v1 说梯度的主方向排序反映了"哪些参数该负责",是测量耦合造成的假象。v2 说开放主方向有额外收益,不存在。v3 说限制方向能改善取舍,不能。

## 二、我们提出过什么优化方法,效果如何

| 版本 | 想法 | 做法 | 结果 |
|---|---|---|---|
| v1 | 按更新在主方向上的位置分配步长 | SSD 优化器 | 想法的前提被推翻,没效果,放弃 |
| v2 | 平时只更新非主方向,有条件时才开放主方向 | PGSU 加门控 | 主方向和随机方向一样,开放它没价值,放弃 |
| v3 | 把更新限制在少数方向上,并放大步长 | 等长度的方向限制 | 没收益,正常训练把学习率调好就能做到一样或更好 |
| v3 | 训练 8 步就预测健康学习率 | 看 8 步内模型输出的变化量 | 两次猜中,但它是个检查工具,不是训练方法 |
| v3 | 一套实验规范 | 随机方向对照、按输出变化量对齐步长、先找健康学习率、检查答题格式、检查 SVD 数值精度 | 防止别人掉坑,不改进训练 |

**一句话:三代方法没有一个在健康学习率下胜过正常训练。我们没有提出任何让后训练变好的方法。** 我们解决的是"为什么之前这类方法看起来有效",答案是步长假象。

## 三、实验结果

设定:Qwen3.5-0.8B,任务 GSM8K(数学题),SFT 和强化学习各训 300 步。任务分数看 GSM8K 准确率,能力保持看 MMLU 准确率。不训练的起点是 GSM8K 0.546、MMLU 0.483。下面的数字都是"GSM8K / MMLU"。

**先找健康学习率**

| | 常用值的 1/30 | 常用值的 1/10(选定) | 常用值的 1/3 |
|---|---|---|---|
| SFT | 0.390 / 0.461 健康 | **0.415 / 0.456** 健康 | 0.420 / 0.302 能力崩 |
| 强化学习 | 0.562 / 0.479 健康 | **0.646 / 0.471** 健康 | 0.699 / 0.457 不同随机种子差太多,能力压线 |

**主实验(都在选定的学习率上)**

| 更新方式 | SFT | 强化学习 |
|---|---|---|
| 正常训练 | 0.415 / 0.456 | 0.646 / 0.471 |
| 不改谱 | 0.400 / 0.454 | 0.634 / 0.473 |
| 故意去谱 | 作废,重做中 | 作废,重做中 |
| 只沿主方向 | 0.389 / 0.474 | 0.556 / 0.478 |
| 只沿随机方向 | 0.375 / 0.475 | 0.556 / 0.477 |

怎么读:
- 主方向和随机方向:SFT 差 0.014,强化学习差 0。分不出。
- 不改谱和正常训练:SFT 差 0.015,强化学习差 0.012。分不出(我们定的"算有差别"的门槛是 0.03)。
- 限制方向和正常训练:SFT 下任务低 0.03、能力高 0.02,是另一个取舍点;强化学习下任务低 0.09、能力一样,全面落后。
- 把限制方向的步长放大 3 倍、10 倍,或学习率调回常用值:SFT 下任务分数不动;强化学习下从 0.56 升到 0.59、0.62,还是不如正常训练的 0.646。

**辅助测量**

- 训练 8 步时,限制方向的更新让模型输出变化的量,只有正常训练的三百分之一(SFT)到三千分之一(强化学习);不改谱的更新和正常训练差不多。
- 训完 300 步,强化学习下限制方向的更新让模型总共只变了正常训练的 1%;SFT 下有 60%。
- 答题格式检查:健康学习率下所有模型格式正常;之前"能力崩到 0.24"的模型是格式坏了;SFT 用常用值的 1/3 训出来的模型是格式坏了加真的变差。
- 故意去谱那一组:实现里用的 GPU SVD 默认算法在单精度下误差有万分之一,每步重设谱时把这个误差当成更新加进去了,相当于每步注入四倍于正常更新的噪声,所以旧结果全部作废。换了高精度算法并把步长对齐后在重做。

**现在到了哪一步。** 手里有一组可靠的否定结论和一条"步长假象"的解释,范围是一个 0.8B 模型、一个任务、300 步。能写成一篇诚实的"我们试了、没用、原因是这个"的短文,分量到不了顶会主会。四个版本下来,"权重主方向"这个视角在每一层都没挖到东西。

# 第二部分:改进方案

## 0. 对目前结果的评估

**一句话:分析没有分析出让人耳目一新的问题,也没有提出任何有效的优化方法。**

- 分析里唯一新的东西是"步长假象"。它可靠,但它是拆穿一个错觉,不是发现一个新问题。其他结论全是"没区别、没用",没有一条会让读者觉得"原来如此"。三个没解释的现象有点意思,但没追出原因。
- 三代方法没有一个胜过正常训练。剩下的检查工具和实验规范是工具,不是方法。
- 现状:一条假象解释、一套规范、一组否定结论,零方法。

**审稿人会怎么看**

| 看什么 | 我们有什么 | 评价 |
|---|---|---|
| 新不新 | "主方向不特殊、限制方向没用、原因是步长假象" | 假象解释是新的;但结论是否定式的,而且现实里没人把更新锁在权重主方向上,这个否定没有对手 |
| 有没有能用的东西 | 检查工具、实验规范 | 都不让训练变好。没有方法 |
| 证据硬不硬 | 每个结论 2 到 6 次实验,差别都在门槛内 | 否定结论靠"分不出差别"证明,两三个种子时统计检验没有区分力;强化学习在这个规模下换个种子就差 0.05 |
| 覆盖面 | 一个 0.8B 模型、一个任务、300 步 | "普遍不特殊"在一个点上立不住 |
| 和已有工作的关系 | 没和 LoRA、PiSSA、SVFT、正交化更新正面比过 | 审稿人第一个问题就是这个 |
| 可靠不可靠 | 崩溃区、格式假象、数值坑、换硬件不复现都抓到了 | 最强的部分,但它是规范贡献,不是科学结论 |

**结论**:现在的结果是一篇可靠、诚实、但没有对手也没有方法的否定式短文。能进 workshop,到不了主会。差的不是实验数量,是一个能用的方法。再做多少分析实验都换不来这个。

## 1. 调研结论(2026-09-17,三路文献调研,原始报告见 `docs/survey_v4_literature.md`)

**我们已有结论里,哪些被人做过了。** "主方向不特殊、收益来自步长"这一条,在 LoRA 初始化这一族里已经有人做了:LoRAM(arXiv 2507.06558)用固定正交基、随机正交基、幅值匹配都复现了 PiSSA/MiLoRA 的收益;"Learning Rate Matters"(2602.04998)把九种 LoRA 变体的学习率调好后差距只剩 1–2%。所以这一半没有新意,只能作为佐证。

**哪些没人做过,而且正是我们能做的。** 有一族新论文把"RL 遗忘少"归因于更新的方向:RLVR 的更新避开权重主方向、保持谱,SFT 则扭曲谱(The Path Not Taken,2511.08567,"三门理论");遗忘来自主方向奇异向量的旋转(Jin 等,2509.12235,提出 rotation-aware SFT 但没验证);MiLoRA、RPSFT、LIFT 都据此主张"保护主方向就少遗忘"。**这些全是描述性统计,没有一篇用匹配步长的对照检验过因果。** 另一边,RL's Razor(2509.04259)说遗忘由模型输出偏离原模型的程度(KL)预测、权重空间指标预测不了,但它只匹配了训练结束时的 KL,Chen 等(2510.18874)给出了 KL 相近而遗忘不同的反例,也没人匹配过 RL 和 SFT 每一步的功能步长看差距是否消失。

也就是说,现在文献里有两种解释在打架:**遗忘取决于"往哪走"(方向说),还是"走了多远"(功能步长说)**。我们的等范数子空间干预和逐矩阵功能步长测量,正是回答这个问题的工具,而且已有一半数据:等范数保谱更新和正常训练在两种范式上遗忘一样,只沿主方向和只沿随机方向一样。这是方向说的直接反证,只是还没按遗忘的口径去测。

**遗忘控制方法这边的现状。** 最强的现成基线:FINCH(2605.20005,全局、按训练损失调学习率,遗忘减 93%,极便宜)、Anchored Learning(2605.04468,全局每步 KL 上界)、对通用数据加 KL 惩罚。按矩阵调步长没人做过,但旁证偏负(2605.22297:分层学习率往往只在全局学习率没调好时才占优)。

**改动压缩**:50–99% 区间已经很挤(DARE、DAREx、ImPart、UltraDelta),按功能贡献选择在大模型上没人干净地做过,但要打的对照多、和我们的主线无关。原方案三删除。

## 2. 改进方案:遗忘是"走了多远"的问题,不是"往哪走"的问题

一句话的论文主张:**后训练的遗忘由每一步让模型输出偏离原模型多少决定,和更新落在权重的哪个方向(主方向、非主方向、保谱、去谱)无关;因此控制遗忘的正确旋钮是功能步长,不是子空间。** 三个部分:一个因果检验(有对手),一个探针(能提前预测),一个方法(能用)。

### 2.1 因果检验(对手:2511.08567、2509.12235、MiLoRA/RPSFT/LIFT 的保持主张)

**做什么。** 在同样的步长(等范数,再加等功能步长)下,把更新分别限制到主方向、随机方向、非主方向(保谱)、去谱、正常训练,直接测遗忘。遗忘用两个口径:MMLU 降幅;以及"任务之外的输出偏离"(在一小组任务外文本上算 KL,用 MMLU 题干或通用文本)。

**已有的。** 五种更新在选定学习率上的 MMLU 全部有(第一部分表);单步 KL 与累计 KL 有,但都是在任务数据上算的。

**要补的。**
1. 任务外 KL:对现有 39 个训完的模型和 8 步捕获,补算任务外文本上的单步 KL 与累计 KL。零训练,一张卡一天。
2. 常用学习率(lr×1)上的保谱与去谱各 2 次,让"方向臂在真的推进了的步长上"也有对照。
3. **RL 与 SFT 每步功能步长匹配**:用 8 步探针把 SFT 的学习率调到"每步任务外 KL 与 RL 相同",训 3 次,看 RL 和 SFT 的 MMLU 差距是否消失。这一条没人做过。

**必须做出的结果。** 五种方向臂之间的遗忘差在门槛内(MMLU 0.02;任务外 KL 差不超过 20%),而学习率一档之差造成的遗忘差远大于此;RL 与 SFT 在每步功能步长匹配后,MMLU 差距至少缩小一半。做到了,方向说被匹配步长的对照否定,功能步长说成立。如果匹配后差距不缩,说明方向确实有作用,论文改写为"方向在哪里起作用",同样成立,只是主张反过来。

### 2.2 探针:训练 8 步预测遗忘

**做什么。** 用 8 步捕获算"任务外 KL / 步长²"(功能杠杆),看它能不能预测训完 300 步后的 MMLU 降幅。

**已有的。** 约 60 次训练的终点 MMLU 和它们的起点配置;8 步捕获 10 组。

**要补的。** 对每个配置补 8 步探针(便宜),把 60 个点画成"探针值 vs 最终遗忘"。再在新模型(Qwen3.5-2B)和新任务(MATH)上先预测后训练。

**必须做出的结果。** 在现有 60 个点上相关性 R² ≥ 0.7,且跨范式、跨干预落在同一条曲线上(这是 RL's Razor 用最终 KL 做到的事,我们要用训练前的探针做到);新设定上的前瞻预测命中健康区。做不到,探针降为描述性指标。

### 2.3 方法:按功能步长做 SFT

**做什么。** 既然遗忘由每步的任务外功能步长决定,就直接把它当旋钮:训练前和每隔 50 步用探针测任务外 KL,把学习率调到目标预算;预算扫三档。全局版先做;按矩阵版(压低"任务外变化多、任务内变化少"的矩阵)作为消融。

**必须打败的对照。** 调好学习率的正常 SFT;对通用数据加 KL 惩罚(每步一次额外前向);FINCH;Anchored Learning。

**必须做出的结果。** 同样的任务分数下 MMLU 不低于最强对照,且开销不高于它;或者同样开销下更好。按矩阵版若不优于全局版,只报全局版。

**老实的预期。** 这部分成功概率中等偏低:FINCH 和 Anchored Learning 已经很强,我们的差异主要在"用训练前探针定预算"和"功能步长的机理解释"。论文的分量来自 2.1 和 2.2;2.3 成了是加分,不成也不影响 2.1、2.2 成文。

## 3. 为什么不够主会

主会对一篇否定结果论文的要求,我们缺三样:

1. **覆盖面不够。** 只有一个模型(Qwen3.5-0.8B)、一个任务(GSM8K)、一个遗忘指标(MMLU)。审稿人对否定结果的第一反应就是"换个规模或任务还成立吗",我们答不上来。
2. **反驳对象没有在对方的设定上复现。** 我们直接反驳的文章(2511.08567、2509.12235、MiLoRA / RPSFT / LIFT 的保持主张)用的是别的模型和任务。我们说"方向无关",他们可以说"设定不一样"。要坐实,必须在他们的设定上跑匹配对照。
3. **没有正向贡献。** "任务外 KL 不是遗忘的代理"和"GPU fp32 SVD 噪声会造出假效果"是有用的提醒,撑不起主会文章。唯一可能的正向点(8 步探针预测功能步长)未验证,即使成立也与"KL 预测遗忘"(2509.04259)差别不大。

补齐前两项至少要 2B 和 3B 各一套、再加一个非数学任务,约两周 GPU、100 个以上 run;第三项赔率中低。最后能否到主会线,估计五五开以下。按"不够主会就不投"的原则,这笔投入不值得。

## 4. 目前能站住的结论(留档)

四个版本、约 100 个训练 run,可靠的有三条:

1. **遗忘由累积功能步长决定,与更新方向无关。** 等范数、等 KL 的方向控制组在健康学习率下与 dense 相同,在崩溃学习率下与 dense 一起崩。单步的任务 / 任务外选择性在 SFT 和 RLVR 之间相同,差异是步子叠加出来的。
2. **任务外 KL 不是能力保持的代理。** 一个方法把它降了三成,MMLU 没变甚至略降。
3. **exact_iso 的"正效果"是 GPU fp32 SVD(gesvdj)噪声,修正后消失。** 任何每步做 SVD 的方法都必须检查这一点。

以及一套实验规范:随机方向对照、按功能步长对齐、先找健康学习率、检查答题格式、检查 SVD 数值精度、换硬件不复现要多种子池化。
