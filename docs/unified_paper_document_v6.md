# 第一部分:问题与现状

**问题:文献里"RL 比 SFT 遗忘少"的差距,在换成不受作答格式影响的读数后还剩多少?差距中格式与知识各占多少?**

**已有工作(09-28 文献调研,子代理报告,关键条目 A 已核对)**

- 遗忘部分来自"对齐 / 格式"而非知识,已有人提出:Spurious Forgetting(2501.13453)、格式特化(2211.00635)、SEFE(2505.02486)、Kotha 等(2309.10105);最接近的是 Knowing but Not Saying(2608.20794,只做 SFT、MedMCQA,认为生成题的失败来自冗长、格式与精确匹配)。**都没有 RL 与 SFT 的对照。**
- "RL 比 SFT 遗忘少"的主要论文:RL's Razor(2509.04259,自己提到格式混淆,用表示相似度回应,没有换读数重测)、Retaining by Doing(2510.18874,**A 已读代码**:MMLU 用正则 `The ... answer is: X` 严格抽取、贪心 4096 token;Llama-8B 上 SFT 掉 27–38 个点而 GRPO 约 0)、机制起源(2605.28860)、SDFT(2601.19897)等。
- **没有找到**有人在格式无关的读数下重测这些差距。
- 反面风险:Luo 等(2308.08747)在似然口径下也观察到遗忘;2603.26556 指出似然口径会掩盖生成能力的损失;CapTrack(2603.06610)认为格式保真本身就是能力。所以论文不写"遗忘是假的",写**差距的分解**。

**主张会是下面三选一(预先写明)**

- A:差距大部分(≥ 50%,置信区间不含 50% 以下)来自格式:RL 的优势主要在于奖励逼它保住答题格式。
- B:差距大部分来自知识:在似然与宽松读数下差距仍在。
- C:介于两者之间:按基准、按模型分别报告格式与知识各占多少。

三种结论都能成文;A 最有冲击力,B 是对该文献的独立加固。

# 第二部分:实验

## 0. 复现(第 0 阶段,约 3 天)

- **对象**:Retaining by Doing,Qwen2.5-1.5B-Instruct 与 Llama-3.2-1B-Instruct(都已在缓存),三个训练任务(MMLU、Countdown、IFEval),三种训练(SFT 专家数据、Self-SFT、GRPO),用**作者公开的代码与数据**(`/scratch/rhong5/rbd`),超参照作者脚本。
- **环境**:作者代码依赖 vllm + ray;用 `~/envs_py310_new`(vllm 0.11、transformers 4.57,足够支持 Qwen2.5 / Llama-3.2)。
- **闸门 R0**:在作者自己的严格口径下复现出他们报告的差距(同模型、同任务的 SFT 降幅与 GRPO 降幅之差在其报告值 ±5 个点内,或方向与量级一致)。复现不出 → 先查原因,不做分解。

## 1. 重测与分解(第 1 阶段,约 3 天)

对每个终点模型,同一批题同时报告:
1. **原口径**(作者的严格正则、生成);
2. **宽松抽取**(答案字母 / 数字出现在最后一句或任何"answer"附近);
3. **写完的题中的正确率**(排除写不完);
4. **似然口径**(MMLU 预填 "The answer is:" 后比较四个字母的概率;不需要模型自己生成格式);
5. **格式遵从率**(写完率、按指令格式作答的比例)。

**分解**:差距(严格)= 差距(似然)+ 格式部分;格式占比 = 1 − 差距(似然)/ 差距(严格),用 run 间方差给置信区间(`analysis_v5/stats.py`)。

**另加一项"格式恢复"检验**:对 SFT 终点模型只用少量(如 64 条)格式示例做几十步短训练或加 few-shot 示例,看严格口径能恢复多少;恢复得越多,越说明丢的是格式。

## 2. 推广(第 2 阶段,约 1 周)

- RL's Razor 的 3B 设定(借 2605.28860 或 SDFT 公开代码):把平均的"旧任务分数"按基准拆成似然型(HellaSwag、Winogrande、MMLU、TruthfulQA-MC)与生成型(IFEval、HumanEval),看差距集中在哪一类。
- UniReason 公开检查点(2507.00432,14B,只做推理评测):RL vs 带思考 SFT vs 不带思考 SFT,格式无关读数重测。

# 第五部分:停止决定(2026-10-01)

**用户原则:不够投主会就不做。A 的判断:不够,停止。**

## 1. v6 得到了什么
- 用原作者代码复现了 Retaining by Doing 的差距(Qwen2.5-1.5B、训练 MMLU):SFT 非目标任务平均降 16.4 个点,GRPO 几乎不降。
- 格式提醒测试(3 道示范题)的分解:**Countdown 的 SFT 遗忘 100% 是格式 / 写不完**(恢复 1.09,示范下 SFT ≥ RL);**MATH 大部分是真实损失**(恢复 0.22,差距 17.5 个点仍在)。原论文的打分把格式崩坏计为遗忘,并会把部分正确答案判错。

## 2. 为什么不够主会
1. 想要的强结论("RL 的优势主要只是格式")不成立,MATH 是反例;"部分是格式、因任务而异"与 Spurious Forgetting(2501.13453)、Knowing but Not Saying(2608.20794)重叠较多。
2. 覆盖面窄:1–1.5B 两个模型、一个训练任务。
3. 没有方法。唯一的潜在方法(格式锚定 SFT)对 MATH 这类真实损失大概率无效;补齐方法 + 两个训练任务 + 7–8B 约 3–5 周,到主会线的把握约三成。
